# i18n / Locale

Two locales ship with the package:

| Code | Language |
|------|----------|
| `en` | English (default) |
| `zh` | 中文 |

```vue
<CronSelector v-model="cron" locale="zh" />
```

The `locale` prop accepts a locale code **or a full `LocaleDefinition` object**, so
you can either use a built-in locale or supply your own.

## Resolving a code

`resolveLocale` is what the component uses internally. It tries the exact code
first, then the base language, then falls back to English:

```ts
resolveLocale('zh')       // Chinese
resolveLocale('zh-CN')    // Chinese — falls back to the base language 'zh'
resolveLocale('fr')       // English — unknown code
```

You can pass a regional code such as `'zh-CN'` or `'en-GB'` directly to the
`locale` prop and it will resolve the same way.

## `LocaleDefinition`

```ts
interface LocaleDefinition {
  code: string                    // BCP 47 code, used for Intl.DateTimeFormat
  name: string
  fieldLabels: Record<string, string>
  tabLabels?: Record<string, string>
  segmentTypes: Record<SegmentType, string>
  periods: Record<PeriodId, string>
  months: string[]                // 12 entries, index 0 = January
  weekdays: string[]              // 7 entries, index 0 = Sunday
  weekdaysShort: string[]
  ui: {
    expand: string
    collapse: string
    nextRuns: string
    invalidExpr: string
    every: string
    at: string
    on: string
    of: string
    and: string
    through: string
    startingAt: string
    from: string
    to: string
    cronExpression: string
    placeholder: string
    everyDay: string
    everyNDaysStartingAt: string        // placeholders: {step} {start}
    specificDayOfWeek: string
    specificDayOfMonth: string
    lastDayOfMonth: string
    lastWeekdayOfMonth: string
    lastSpecificWeekdayOfMonth: string  // placeholder: {weekday}
    daysBeforeEndOfMonth: string        // placeholder: {n}
    nearestWeekdayTo: string            // placeholder: {day}
    nthWeekdayOfMonth: string           // placeholders: {nth} {weekday}
    day: string
    days: string
    the: string
    ordinals: string[]                  // ['1st', '2nd', '3rd', '4th', '5th']
    fieldOptions: Record<string, {
      everyOne: string
      step: string
      specific: string
      range: string
    }>
    selectPlaceholder: string
  }
}
```

Strings marked with placeholders are interpolated at render time — `{n}` in
`daysBeforeEndOfMonth` becomes the numeric offset, for example.

## Custom locale

The shortest path is to derive from a built-in locale and override what you need:

```ts
import { EN_LOCALE, type LocaleDefinition } from 'vue3-cron-selector'

const jaLocale: LocaleDefinition = {
  ...EN_LOCALE,
  code: 'ja',
  name: '日本語',
  fieldLabels: {
    second: '秒',
    minute: '分',
    hour: '時',
    dayOfMonth: '日',
    month: '月',
    dayOfWeek: '曜日',
    year: '年',
  },
  months: ['1月', '2月', '3月', '4月', '5月', '6月', '7月', '8月', '9月', '10月', '11月', '12月'],
  weekdays: ['日曜日', '月曜日', '火曜日', '水曜日', '木曜日', '金曜日', '土曜日'],
  weekdaysShort: ['日', '月', '火', '水', '木', '金', '土'],
}
```

```vue
<CronSelector v-model="cron" :locale="jaLocale" />
```

If you prefer a shallow object as the starting point, `ZH_LOCALE` is exported too.
`LocaleDefinition` is also importable as a type: `import type { LocaleDefinition }
from 'vue3-cron-selector'`.

::: tip Weekday and month naming
`weekdays` and `weekdaysShort` are indexed from Sunday (index 0), and `months` from
January (index 0), matching the numeric values the selector uses for those fields.
:::

## Reading a value label

To format a single value the way the selector does (month names, weekday names),
use `getFieldValueLabel`:

```ts
import { ZH_LOCALE, getFieldValueLabel } from 'vue3-cron-selector'

getFieldValueLabel('month', 3, ZH_LOCALE)     // "3月"
getFieldValueLabel('dayOfWeek', 1, ZH_LOCALE) // "周一"
getFieldValueLabel('minute', 5, ZH_LOCALE)    // "05"
```
