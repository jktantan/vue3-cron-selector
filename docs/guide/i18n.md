# i18n / Locale

Two locales ship with the package:

| Code | Language |
|------|----------|
| `en-US` | English (United States, default) |
| `zh-CN` | 简体中文 |

Bare `en` and `zh` are accepted as aliases for `en-US` and `zh-CN`.

```vue
<CronSelector v-model="cron" locale="zh-CN" />
```

The `locale` prop accepts a locale code **or a full `LocaleDefinition` object**, so
you can either use a built-in locale or supply your own.

## Resolving a code

`resolveLocale` tries the exact BCP 47 tag, then the base language, then English.
A regional tag that resolves to a base language is kept in `code`, so
`Intl.DateTimeFormat` and `Intl.PluralRules` still format for that region:

```ts
resolveLocale('zh-CN')    // ZH_CN_LOCALE, code 'zh-CN'
resolveLocale('zh')       // ZH_CN_LOCALE (alias), code 'zh-CN'
resolveLocale('zh-cn')    // canonicalised to 'zh-CN', same pack
resolveLocale('zh-TW')    // Chinese copy, code 'zh-TW' — Intl uses Taiwan formats
resolveLocale('en-GB')    // English copy, code 'en-GB'
resolveLocale('en')       // EN_US_LOCALE (alias), code 'en-US'
resolveLocale('fr')       // EN_US_LOCALE, code 'en-US'
```

Tags are canonicalised with `Intl.getCanonicalLocales`, so `'EN-us'` becomes
`'en-US'`. Until a regional pack exists, only the copy falls back to the base
language; date and number formatting already honours the region.

## `LocaleDefinition`

```ts
interface PluralForms {
  one?: string
  few?: string
  many?: string
  other: string   // required fallback
}

interface FieldOptionLabels {
  everyOne: string
  step: string
  specific: string
  range: string
}

interface LocaleDefinition {
  code: string                    // BCP 47 tag, used by Intl
  name: string                    // endonym, e.g. "English" / "中文"
  fields: {
    labels: Record<string, string>  // long names: "Minute", "Day of Month"
    tabs: Record<string, string>    // short tab names: "Min", "Day"
  }
  segmentTypes: Record<SegmentType, string>
  periods: Record<PeriodId, string>
  units: Record<string, PluralForms>   // countable words, keyed by field id
  ordinals: string[]                   // ["1st", "2nd", ...]
  months: string[]                     // 12 entries, index 0 = January
  weekdays: string[]                   // 7 entries, index 0 = Sunday
  weekdaysShort: string[]
  ui: {
    expand: string
    collapse: string
    nextRuns: string
    invalidExpr: string
    cronExpression: string
    placeholder: string
    selectPlaceholder: string
    fieldOptions: Record<string, FieldOptionLabels>
  }
  templates: {
    step: string                       // tokens: {step} {unit} {base}
    range: string                      // tokens: {from} {to} {unit}
    day: {
      everyDay: string
      everyNStartingAt: string         // tokens: {step} {unit} {base}
      specificDayOfWeek: string
      specificDayOfMonth: string
      lastDayOfMonth: string
      lastBusinessDayOfMonth: string
      lastWeekdayOfMonth: string       // token: {weekday}
      daysBeforeEndOfMonth: string     // tokens: {n} {unit}
      nearestWeekdayTo: string         // token: {day}
      nthWeekdayOfMonth: string        // tokens: {nth} {weekday}
    }
    description: {
      everyPeriod: string              // {period}
      everyField: string               // {field}
      step: string                     // {step} {unit}
      stepWithBase: string             // {step} {unit} {base}
      range: string                    // {from} {to}
      atTime: string                   // {hour} {minute}
      atHourMinute: string             // {hour} {minute}
      atField: string                  // {field} {value}
      on: string                       // {value}
      onDayOfMonth: string             // {value}
      inMonth: string                  // {value}
      year: string                     // {value}
      list: string                     // {head} {last}
      clauseSeparator: string
      listSeparator: string
    }
  }
}
```

### The locale owns word order

Every sentence is a template. Components render the literal text and place a
control where a token sits:

| Token | Filled by |
|-------|-----------|
| `{step}`, `{base}`, `{from}`, `{to}`, `{n}`, `{day}` | number spinners |
| `{weekday}`, `{nth}` | inline selects |
| `{unit}` | the field's unit word in the form that matches the count |
| `{period}`, `{field}`, `{value}`, `{hour}`, `{minute}`, `{time}`, `{head}`, `{last}` | already-formatted labels or clauses |

Because the tokens are part of the template, English can put the number before
the unit while Chinese puts a comma and a trailing particle between them, with
no component-side concatenation.

### Plurals

`units` holds word forms, not a hard-coded singular/plural pair. The selector
picks the form with `Intl.PluralRules` for `locale.code`:

```ts
units: {
  minute: { one: 'minute', other: 'minutes' },
  dayOfMonth: { one: 'day', other: 'days' },
}
```

A language with a single form only needs `other`:

```ts
units: {
  minute: { other: '分钟' },
  dayOfMonth: { other: '天' },
}
```

## Custom locale

The shortest path is to derive from a built-in locale and override what you need.
Translating `templates` is what makes the word order natural; translating only
`fields` and `months` keeps the source language's sentence structure:

```ts
import { EN_US_LOCALE, type LocaleDefinition } from 'vue3-cron-selector'

const jaLocale: LocaleDefinition = {
  ...EN_US_LOCALE,
  code: 'ja',
  name: '日本語',
  fields: {
    ...EN_US_LOCALE.fields,
    labels: {
      second: '秒',
      minute: '分',
      hour: '時',
      dayOfMonth: '日',
      month: '月',
      dayOfWeek: '曜日',
      year: '年',
    },
    tabs: {
      second: '秒',
      minute: '分',
      hour: '時',
      dayOfMonth: '日',
      month: '月',
      dayOfWeek: '曜日',
      year: '年',
    },
  },
  units: {
    second: { other: '秒' },
    minute: { other: '分' },
    hour: { other: '時間' },
    dayOfMonth: { other: '日' },
    month: { other: 'か月' },
    dayOfWeek: { other: '曜日' },
    year: { other: '年' },
  },
  months: ['1月', '2月', '3月', '4月', '5月', '6月', '7月', '8月', '9月', '10月', '11月', '12月'],
  weekdays: ['日曜日', '月曜日', '火曜日', '水曜日', '木曜日', '金曜日', '土曜日'],
  weekdaysShort: ['日', '月', '火', '水', '木', '金', '土'],
  templates: {
    ...EN_US_LOCALE.templates,
    step: '{step} {unit}、{base} から',
    day: {
      ...EN_US_LOCALE.templates.day,
      everyDay: '毎日',
      everyNStartingAt: '{step} {unit}ごとに、毎月 {base} 日から',
    },
  },
}
```

```vue
<CronSelector v-model="cron" :locale="jaLocale" />
```

`ZH_CN_LOCALE` is exported as well if you prefer a Chinese base. `LocaleDefinition`
is importable as a type: `import type { LocaleDefinition } from 'vue3-cron-selector'`.

::: tip Weekday and month naming
`weekdays` and `weekdaysShort` are indexed from Sunday (index 0), and `months` from
January (index 0), matching the numeric values the selector uses for those fields.
:::

## Reading a value label

To format a single value the way the selector does (month names, weekday names),
use `getFieldValueLabel`:

```ts
import { ZH_CN_LOCALE, getFieldValueLabel } from 'vue3-cron-selector'

getFieldValueLabel('month', 3, ZH_CN_LOCALE)     // "三月"
getFieldValueLabel('dayOfWeek', 1, ZH_CN_LOCALE) // "星期一"
getFieldValueLabel('minute', 5, ZH_CN_LOCALE)    // "05"
```

## Migrating from 0.2

The locale API was reorganised in 0.3 to remove ambiguous keys and sentence
fragments. Old custom locales need these renames:

| 0.2 | 0.3 |
|-----|-----|
| `fieldLabels` | `fields.labels` |
| `tabLabels` | `fields.tabs` |
| `ui.ordinals` | `ordinals` |
| `ui.everyDay` | `templates.day.everyDay` |
| `ui.everyNDaysStartingAt` (`{start}`) | `templates.day.everyNStartingAt` (`{base}`) |
| `ui.specificDayOfWeek` | `templates.day.specificDayOfWeek` |
| `ui.specificDayOfMonth` | `templates.day.specificDayOfMonth` |
| `ui.lastDayOfMonth` | `templates.day.lastDayOfMonth` |
| `ui.lastWeekdayOfMonth` (`LW`) | `templates.day.lastBusinessDayOfMonth` |
| `ui.lastSpecificWeekdayOfMonth` (`nL`) | `templates.day.lastWeekdayOfMonth` |
| `ui.daysBeforeEndOfMonth` | `templates.day.daysBeforeEndOfMonth` |
| `ui.nearestWeekdayTo` | `templates.day.nearestWeekdayTo` |
| `ui.nthWeekdayOfMonth` | `templates.day.nthWeekdayOfMonth` |
| `ui.stepWithBase` | `templates.step` |
| `ui.every`, `at`, `on`, `of`, `and`, `through`, `startingAt`, `from`, `to`, `day`, `days`, `the` | removed — use a whole-sentence template |
| `segmentTypes.lastWeekday` | `segmentTypes.lastBusinessDay` |
| `SegmentType` `'lastWeekday'` | `'lastBusinessDay'` |
| `EN_LOCALE` | `EN_US_LOCALE` |
| `ZH_LOCALE` | `ZH_CN_LOCALE` |
| `'en'` / `'zh'` | Still accepted as aliases for `'en-US'` / `'zh-CN'` |

`day` / `days` and the `(s)` suffix are replaced by `units` plus
`Intl.PluralRules`.
