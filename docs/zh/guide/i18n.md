# 国际化

本包内置两种语言：

| 代码 | 语言 |
|------|------|
| `en` | 英文（默认） |
| `zh` | 中文 |

```vue
<CronSelector v-model="cron" locale="zh" />
```

`locale` 属性既可以接受语言代码，**也可以接受完整的 `LocaleDefinition` 对象**，
因此你既能使用内置语言，也能提供自己的语言。

## 语言代码的解析顺序

组件内部使用的正是 `resolveLocale`。它会先尝试精确匹配，再尝试基础语言，最后回退到
英文：

```ts
resolveLocale('zh')       // 中文
resolveLocale('zh-CN')    // 中文 —— 回退到基础语言 'zh'
resolveLocale('fr')       // 英文 —— 未知代码
```

你也可以直接把 `'zh-CN'`、`'en-GB'` 这类区域代码传给 `locale` 属性，解析规则相同。

## `LocaleDefinition`

```ts
interface LocaleDefinition {
  code: string                    // BCP 47 代码，用于 Intl.DateTimeFormat
  name: string
  fieldLabels: Record<string, string>
  tabLabels?: Record<string, string>
  segmentTypes: Record<SegmentType, string>
  periods: Record<PeriodId, string>
  months: string[]                // 12 项，索引 0 为 1 月
  weekdays: string[]              // 7 项，索引 0 为周日
  weekdaysShort: string[]
  ui: {
    expand: string
    collapse: string
    nextRuns: string
    invalidExpr: string
    every: string
    at: string
    on: string
    of: string
    and: string
    through: string
    startingAt: string
    from: string
    to: string
    cronExpression: string
    placeholder: string
    everyDay: string
    everyNDaysStartingAt: string        // 占位符：{step} {start}
    specificDayOfWeek: string
    specificDayOfMonth: string
    lastDayOfMonth: string
    lastWeekdayOfMonth: string
    lastSpecificWeekdayOfMonth: string  // 占位符：{weekday}
    daysBeforeEndOfMonth: string        // 占位符：{n}
    nearestWeekdayTo: string            // 占位符：{day}
    nthWeekdayOfMonth: string           // 占位符：{nth} {weekday}
    day: string
    days: string
    the: string
    ordinals: string[]                  // ['1st', '2nd', '3rd', '4th', '5th']
    fieldOptions: Record<string, {
      everyOne: string
      step: string
      specific: string
      range: string
    }>
    selectPlaceholder: string
  }
}
```

带占位符的字符串会在渲染时插值 —— 例如 `daysBeforeEndOfMonth` 中的 `{n}` 会被替换为
数字偏移量。

## 自定义语言

最省事的方式是在内置语言的基础上派生，只覆盖需要改的部分：

```ts
import { ZH_LOCALE, type LocaleDefinition } from 'vue3-cron-selector'

const koLocale: LocaleDefinition = {
  ...ZH_LOCALE,
  code: 'ko',
  name: '한국어',
  fieldLabels: {
    second: '초',
    minute: '분',
    hour: '시',
    dayOfMonth: '일',
    month: '월',
    dayOfWeek: '요일',
    year: '년',
  },
  months: ['1월', '2월', '3월', '4월', '5월', '6월', '7월', '8월', '9월', '10월', '11월', '12월'],
  weekdays: ['일요일', '월요일', '화요일', '수요일', '목요일', '금요일', '토요일'],
  weekdaysShort: ['일', '월', '화', '수', '목', '금', '토'],
}
```

```vue
<CronSelector v-model="cron" :locale="koLocale" />
```

`EN_LOCALE` 同样被导出，可作为英文基准。`LocaleDefinition` 也可以作为类型导入：
`import type { LocaleDefinition } from 'vue3-cron-selector'`。

::: tip 月份与星期的取名规则
`weekdays` 与 `weekdaysShort` 从周日开始（索引 0），`months` 从 1 月开始（索引 0），
与选择器内部使用的数值一致。
:::

## 读取单个值的标签

如果需要按选择器的方式格式化单个值（月份名、星期名），使用 `getFieldValueLabel`：

```ts
import { ZH_LOCALE, getFieldValueLabel } from 'vue3-cron-selector'

getFieldValueLabel('month', 3, ZH_LOCALE)     // "3月"
getFieldValueLabel('dayOfWeek', 1, ZH_LOCALE) // "周一"
getFieldValueLabel('minute', 5, ZH_LOCALE)    // "05"
```
