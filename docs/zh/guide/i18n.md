# 国际化

本包内置两种语言：

| 代码 | 语言 |
|------|------|
| `en-US` | 英文（美国，默认） |
| `zh-CN` | 简体中文 |

`en` 与 `zh` 仍可作为 `en-US`、`zh-CN` 的别名使用。

```vue
<CronSelector v-model="cron" locale="zh-CN" />
```

`locale` 属性既可以接受语言代码，**也可以接受完整的 `LocaleDefinition` 对象**，
因此你既能使用内置语言，也能提供自己的语言。

## 语言代码的解析顺序

`resolveLocale` 会先尝试精确匹配 BCP 47 标签，再尝试基础语言，最后回退到英文。
当区域标签回退到基础语言时，返回对象的 `code` 仍保留区域标签，因此
`Intl.DateTimeFormat` 与 `Intl.PluralRules` 依旧按该区域格式化：

```ts
resolveLocale('zh-CN')    // ZH_CN_LOCALE，code 为 'zh-CN'
resolveLocale('zh')       // ZH_CN_LOCALE（别名），code 为 'zh-CN'
resolveLocale('zh-cn')    // 规范化为 'zh-CN'，同一个语言包
resolveLocale('zh-TW')    // 中文文案，code 为 'zh-TW'，Intl 使用台湾格式
resolveLocale('en-GB')    // 英文文案，code 为 'en-GB'
resolveLocale('en')       // EN_US_LOCALE（别名），code 为 'en-US'
resolveLocale('fr')       // EN_US_LOCALE，code 为 'en-US'
```

标签会先经 `Intl.getCanonicalLocales` 规范化，例如 `'EN-us'` 会变成 `'en-US'`。
在区域语言包出现之前，只有文案回退到基础语言；日期与数字格式已经按区域生效。

## `LocaleDefinition`

```ts
interface PluralForms {
  one?: string
  few?: string
  many?: string
  other: string   // 必需的兜底词形
}

interface FieldOptionLabels {
  everyOne: string
  step: string
  specific: string
  range: string
}

interface LocaleDefinition {
  code: string                    // BCP 47 标签，用于 Intl
  name: string                    // 语言自称，例如 "English" / "中文"
  fields: {
    labels: Record<string, string>  // 长名称："分钟"、"日"
    tabs: Record<string, string>    // tab 短名称："分"、"天"
  }
  segmentTypes: Record<SegmentType, string>
  periods: Record<PeriodId, string>
  units: Record<string, PluralForms>   // 可数名词词形，按字段 id 索引
  ordinals: string[]                   // ["第一", "第二", ...]
  months: string[]                     // 12 项，索引 0 为 1 月
  weekdays: string[]                   // 7 项，索引 0 为周日
  weekdaysShort: string[]
  ui: {
    expand: string
    collapse: string
    nextRuns: string
    invalidExpr: string
    cronExpression: string
    placeholder: string
    selectPlaceholder: string
    fieldOptions: Record<string, FieldOptionLabels>
  }
  templates: {
    step: string                       // token：{step} {unit} {base}
    range: string                      // token：{from} {to} {unit}
    day: {
      everyDay: string
      everyNStartingAt: string         // token：{step} {unit} {base}
      specificDayOfWeek: string
      specificDayOfMonth: string
      lastDayOfMonth: string
      lastBusinessDayOfMonth: string
      lastWeekdayOfMonth: string       // token：{weekday}
      daysBeforeEndOfMonth: string     // token：{n} {unit}
      nearestWeekdayTo: string         // token：{day}
      nthWeekdayOfMonth: string        // token：{nth} {weekday}
    }
    description: {
      everyPeriod: string              // {period}
      everyField: string               // {field}
      step: string                     // {step} {unit}
      stepWithBase: string             // {step} {unit} {base}
      range: string                    // {from} {to}
      atTime: string                   // {hour} {minute}
      atHourMinute: string             // {hour} {minute}
      atField: string                  // {field} {value}
      on: string                       // {value}
      onDayOfMonth: string             // {value}
      inMonth: string                  // {value}
      year: string                     // {value}
      list: string                     // {head} {last}
      clauseSeparator: string
      listSeparator: string
    }
  }
}
```

### 词序由语言包决定

每个句子都是一个模板。组件只渲染字面文本，并在 token 所在的位置放置控件：

| Token | 由什么填充 |
|-------|-----------|
| `{step}`、`{base}`、`{from}`、`{to}`、`{n}`、`{day}` | 数字步进器 |
| `{weekday}`、`{nth}` | 内联下拉框 |
| `{unit}` | 字段的单位词，按数量选择正确词形 |
| `{period}`、`{field}`、`{value}`、`{hour}`、`{minute}`、`{time}`、`{head}`、`{last}` | 已格式化的标签或子句 |

因为 token 属于模板，英文可以把数字放在单位前，中文可以在两者之间加逗号和助词，
组件侧不需要做任何拼接。

### 复数

`units` 保存的是词形，而不是写死的单复数对。选择器会用 `locale.code` 创建
`Intl.PluralRules`，再挑选对应词形：

```ts
units: {
  minute: { one: 'minute', other: 'minutes' },
  dayOfMonth: { one: 'day', other: 'days' },
}
```

只有单一词形的语言只需提供 `other`：

```ts
units: {
  minute: { other: '分钟' },
  dayOfMonth: { other: '天' },
}
```

## 自定义语言

最省事的方式是在内置语言的基础上派生，只覆盖需要改的部分。真正让语序自然的是
`templates`；只翻译 `fields` 与 `months` 会保留源语言的句子结构：

```ts
import { EN_US_LOCALE, type LocaleDefinition } from 'vue3-cron-selector'

const jaLocale: LocaleDefinition = {
  ...EN_US_LOCALE,
  code: 'ja',
  name: '日本語',
  fields: {
    ...EN_US_LOCALE.fields,
    labels: {
      second: '秒',
      minute: '分',
      hour: '時',
      dayOfMonth: '日',
      month: '月',
      dayOfWeek: '曜日',
      year: '年',
    },
    tabs: {
      second: '秒',
      minute: '分',
      hour: '時',
      dayOfMonth: '日',
      month: '月',
      dayOfWeek: '曜日',
      year: '年',
    },
  },
  units: {
    second: { other: '秒' },
    minute: { other: '分' },
    hour: { other: '時間' },
    dayOfMonth: { other: '日' },
    month: { other: 'か月' },
    dayOfWeek: { other: '曜日' },
    year: { other: '年' },
  },
  months: ['1月', '2月', '3月', '4月', '5月', '6月', '7月', '8月', '9月', '10月', '11月', '12月'],
  weekdays: ['日曜日', '月曜日', '火曜日', '水曜日', '木曜日', '金曜日', '土曜日'],
  weekdaysShort: ['日', '月', '火', '水', '木', '金', '土'],
  templates: {
    ...EN_US_LOCALE.templates,
    step: '{step} {unit}、{base} から',
    day: {
      ...EN_US_LOCALE.templates.day,
      everyDay: '毎日',
      everyNStartingAt: '{step} {unit}ごとに、毎月 {base} 日から',
    },
  },
}
```

```vue
<CronSelector v-model="cron" :locale="jaLocale" />
```

`ZH_CN_LOCALE` 同样被导出，可作为中文基准。`LocaleDefinition` 也可以作为类型导入：
`import type { LocaleDefinition } from 'vue3-cron-selector'`。

::: tip 月份与星期的取名规则
`weekdays` 与 `weekdaysShort` 从周日开始（索引 0），`months` 从 1 月开始（索引 0），
与选择器内部使用的数值一致。
:::

## 读取单个值的标签

如果需要按选择器的方式格式化单个值（月份名、星期名），使用 `getFieldValueLabel`：

```ts
import { ZH_CN_LOCALE, getFieldValueLabel } from 'vue3-cron-selector'

getFieldValueLabel('month', 3, ZH_CN_LOCALE)     // "三月"
getFieldValueLabel('dayOfWeek', 1, ZH_CN_LOCALE) // "星期一"
getFieldValueLabel('minute', 5, ZH_CN_LOCALE)    // "05"
```

## 从 0.2 迁移

0.3 重新组织了语言包结构，去掉了歧义键名与句子碎片。已有的自定义语言包需要按
下表改名：

| 0.2 | 0.3 |
|-----|-----|
| `fieldLabels` | `fields.labels` |
| `tabLabels` | `fields.tabs` |
| `ui.ordinals` | `ordinals` |
| `ui.everyDay` | `templates.day.everyDay` |
| `ui.everyNDaysStartingAt`（`{start}`） | `templates.day.everyNStartingAt`（`{base}`） |
| `ui.specificDayOfWeek` | `templates.day.specificDayOfWeek` |
| `ui.specificDayOfMonth` | `templates.day.specificDayOfMonth` |
| `ui.lastDayOfMonth` | `templates.day.lastDayOfMonth` |
| `ui.lastWeekdayOfMonth`（`LW`） | `templates.day.lastBusinessDayOfMonth` |
| `ui.lastSpecificWeekdayOfMonth`（`nL`） | `templates.day.lastWeekdayOfMonth` |
| `ui.daysBeforeEndOfMonth` | `templates.day.daysBeforeEndOfMonth` |
| `ui.nearestWeekdayTo` | `templates.day.nearestWeekdayTo` |
| `ui.nthWeekdayOfMonth` | `templates.day.nthWeekdayOfMonth` |
| `ui.stepWithBase` | `templates.step` |
| `ui.every`、`at`、`on`、`of`、`and`、`through`、`startingAt`、`from`、`to`、`day`、`days`、`the` | 已移除，改用整句模板 |
| `segmentTypes.lastWeekday` | `segmentTypes.lastBusinessDay` |
| `SegmentType` 的 `'lastWeekday'` | `'lastBusinessDay'` |
| `EN_LOCALE` | `EN_US_LOCALE` |
| `ZH_LOCALE` | `ZH_CN_LOCALE` |
| `'en'` / `'zh'` | 仍作为 `'en-US'` / `'zh-CN'` 的别名被接受 |

`day` / `days` 和 `(s)` 后缀由 `units` 与 `Intl.PluralRules` 取代。
