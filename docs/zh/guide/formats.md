# 格式说明

`format` 属性决定使用哪种 Cron 方言。字段数量、字段顺序以及允许的特殊字符都会随之
变化。

| `format` | 字段数 | 方言 |
|----------|--------|------|
| `crontab` | 5 | 标准 crontab |
| `spring` | 6 | Spring `@Scheduled` cron |
| `quartz` | 7（年份可省略） | Quartz Scheduler |

## crontab（5 位）

```
┌───────────── 分钟 (0-59)
│ ┌───────────── 小时 (0-23)
│ │ ┌───────────── 日 (1-31)
│ │ │ ┌───────────── 月 (1-12)
│ │ │ │ ┌───────────── 星期 (0-6)
* * * * *
```

```vue
<CronSelector v-model="cron" format="crontab" />
```

## quartz（7 位，年份可省略）

```
┌───────────── 秒 (0-59)
│ ┌───────────── 分钟 (0-59)
│ │ ┌───────────── 小时 (0-23)
│ │ │ ┌───────────── 日 (1-31)
│ │ │ │ ┌───────────── 月 (1-12)
│ │ │ │ │ ┌───────────── 星期 (0-6)
│ │ │ │ │ │ ┌───────────── 年 (1970-2099)
0 * * * * ? *
```

Quartz 接受 6 位或 7 位：省略末位年份时按 `*` 处理。因此 `0 * * * * ?` 与
`0 * * * * ? *` 都是合法的。

```vue
<CronSelector v-model="cron" format="quartz" />
```

Quartz 还允许在 `dayOfMonth` 与 `dayOfWeek` 字段中使用 `?`，表示"不指定"。在
crontab 模式下 `?` 会被拒绝，用在其他字段上同样会触发校验错误。

## spring（6 位）

```
┌───────────── 秒 (0-59)
│ ┌───────────── 分钟 (0-59)
│ │ ┌───────────── 小时 (0-23)
│ │ │ ┌───────────── 日 (1-31)
│ │ │ │ ┌───────────── 月 (1-12)
│ │ │ │ │ ┌───────────── 星期 (0-6)
0 * * * * *
```

```vue
<CronSelector v-model="cron" format="spring" />
```

## 字段取值范围

| 字段 | 最小值 | 最大值 | 说明 |
|------|--------|--------|------|
| `second` | 0 | 59 | 仅 Quartz 与 Spring |
| `minute` | 0 | 59 | |
| `hour` | 0 | 23 | |
| `dayOfMonth` | 1 | 31 | Quartz 模式下支持 `L`、`L-n`、`nW` |
| `month` | 1 | 12 | 接受 `JAN`–`DEC` |
| `weekday` | 0 | 6 | 接受 `SUN`–`SAT` |
| `year` | 1970 | 2099 | 仅 Quartz，可省略 |

## 运行时切换格式

切换 `format` 会重建编辑器，但**不会改动**你已有的表达式 —— 因为格式转换可能是有损的：
crontab 没有秒字段，`0 * * * * ? *` 无法在其中表示。如需在切换后回到该格式的默认值，
请自行更新表达式，或调用 `useCron` 组合式函数的 `reset()`。
